====================================================================
Git Commands Used During the Assignment
====================================================================

1. git init
   Initializes a new empty Git repository in the current folder,
   creating a hidden .git directory to track version history.

2. git add <filename>
   Stages a specific file, preparing it to be included in the
   next commit. Use "git add ." to stage all changes at once.

3. git commit -m "message"
   Records the staged changes permanently in the repository history
   with a descriptive message explaining what was changed.

4. git checkout -b feature
   Creates a new branch named "feature" and immediately switches
   to it, allowing isolated development without affecting main.

5. git checkout main
   Switches back to the main branch from the current branch,
   updating the working directory to reflect the main branch state.

6. git merge feature
   Merges all commits from the "feature" branch into the currently
   active branch (main), combining their change histories.

7. git log --oneline --graph --all
   Displays the full commit history in a compact one-line format
   with an ASCII graph showing all branches and their relationships.

8. git status
   Shows the current state of the working directory and staging area,
   listing modified, staged, and untracked files.

9. git reset --soft HEAD~1
   Undoes the last commit but keeps the changes staged (ready to
   re-commit). HEAD~1 means "one commit behind the current HEAD".

10. git restore --staged <filename>
    Removes a file from the staging area (unstages it) without
    discarding the actual file changes in the working directory.

11. git remote add origin <URL>
    Links the local repository to a remote GitHub repository by
    giving it the alias "origin" and specifying its URL.

12. git push -u origin main
    Pushes all commits from the local main branch to the remote
    GitHub repository and sets origin/main as the upstream tracker.
